## 로컬에서 보기

빌드 과정이 없는 정적 사이트라서 `index.html`을 브라우저로 열면 바로 볼 수 있습니다.

로컬 서버로 띄우고 싶다면 프로젝트 폴더에서 아래 중 하나를 실행한 뒤 http://localhost:8000 에 접속하세요.

```bash
# Python이 설치되어 있을 때
python -m http.server 8000

# Node.js가 설치되어 있을 때
npx serve -l 8000
```
